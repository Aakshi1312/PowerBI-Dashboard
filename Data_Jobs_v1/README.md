# DATA JOBS DASHBOARD

![alt text](/images/data%20dashboard.jpg)

## This dashboards was created for **Job seekers , Job Transitioners , and Job Swappers** to solve a common probklem: information about the data job market is scattered and hard to grasp. Using a _real word data set of 2024data Science job postings_ (including titles, salary and locations,) this project provides a single, easy to useinterface to explore markettrends and compensation

## Skills Showcased

- **Data Transformation for power querry:** Cleaned, shaped and prepared the row data for analysis by handling blanks, changing data types and creating new column.

- **Implicit Measures:** Formulated measure to derive Key insights and KPIs like 'Median Yearly Salary' and 'Job Count'

- **Core Charts :** Utilize **Columns , Bars, Line,** and **Area Charts**
  to compare job counts and track trends over time

- **Geospatical Analaysis** : Leveraged **Map Chart** To visual the global distribution of jobs

- **KPI indicators and Maps:** Used **Cards** to display key matrics and **Tables** to provide granular ,sortable data
- **Dashboard Design:** Designed intutaive and visually appealing layout,exploraing both common and uncommon chart types to best tell the data story.

- **Interactive Reporting:**
  - **Slicers :** To dynamically filter the reports by job title
  - **Buttons & Bookmarks :** To create a seamless navigation experience
  - **Drill Through :**To navigate from high level summary to a contextual, detailed view .
